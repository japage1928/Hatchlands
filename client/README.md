# Hatchlands Client

React + Vite PWA client. Creatures are rendered as 2D PNG sprites.

## Develop

```bash
npm ci                          # from the repo root
npm run dev --workspace=client  # http://localhost:5173/Hatchlands/
npm run build --workspace=client
```

The Vite `base` is `/Hatchlands/` (GitHub Pages project site), so all asset URLs go through `import.meta.env.BASE_URL`.

## Layout

```
src/
  api/          HTTP client (needs the optional server; the hosted site has none)
  components/   React UI; CreatureViewer shows sprites/<species>.png with a placeholder fallback
  systems/      Progression logic
  utils/        Helpers
  pwa.ts        Install prompt / service worker helpers
public/
  sprites/      Species PNGs (14 of 15; behemoth uses the placeholder)
  icons/        Placeholder PWA icons
```

PWA manifest and service worker are generated by `vite-plugin-pwa` (see `vite.config.ts`).
